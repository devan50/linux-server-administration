      
# Lab 04: Networking and SSH

## Objective
Inspect network configuration and SSH service availability
on AlmaLinux.

## Commands Practiced
- `ip addr` - Inspect network interfaces and IP addresses.
- `ip route` - Inspect the routing table.
- `cat /etc/resolv.conf` - Inspect DNS resolver settings.
- `systemctl is-active sshd` - Check SSH service status.
- `firewall-cmd --list-all` - Inspect firewall configuration.

## Learning Outcome
