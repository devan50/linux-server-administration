# Lab 03: Linux Service Management

## Objective
Learn to inspect and manage Linux services using systemctl.

## Commands Practiced
- systemctl status sshd
- systemctl status firewalld
- systemctl status nginx
- systemctl is-active nginx
- systemctl is-enabled nginx

## Learning Outcome
Learned how to inspect service status and distinguish
between whether a service is running and whether it
is configured to start automatically at boot.
