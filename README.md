
# Linux Server Administration Lab

## Overview
A hands-on project documenting Linux server administration
and troubleshooting using AlmaLinux.

## Objectives
- Manage Linux users and groups
- Configure file permissions
- Manage system services using systemctl
- Understand SSH and firewall configuration
- Practice disk and filesystem management
- Troubleshoot common Linux issues

## Environment
- OS: AlmaLinux
- Shell: Bash
- Virtualization: VirtualBox

## Lab Modules
1. Users and Permissions
2. System Services
3. Networking and SSH
4. Storage Management
5. Troubleshooting
